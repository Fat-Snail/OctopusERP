# OctopusOA — H5 移动端功能规格

## 概述

OctopusOA 是企业办公自动化系统，H5 版本面向**员工日常使用场景**，聚焦高频操作。
登录方式：SSO（通过 UMC OIDC 授权码流 + PKCE），无独立账号体系。

---

## 导航架构

### 底部 TabBar（4 Tab）

```
[首页]  [审批]  [考勤]  [我的]
 Home   Approval  Attend  Profile
```

| Tab | 图标 | 路由 | 徽标 |
|---|---|---|---|
| 首页 | `Home` | `/` | 待办总数（红点） |
| 审批 | `ClipboardList` | `/approval` | 待审批数 |
| 考勤 | `Clock` | `/attendance` | 今日未打卡时亮橙点 |
| 我的 | `User` | `/profile` | 无 |

| 今日会议 | `summary.todayMeetings` | info |

**快捷操作**：点击直跳对应一级页面

| type | 渲染组件 |
|---|---|
| `text` | Input |
| `textarea` | Textarea |
| `select` | 底部弹层 ActionSheet 选择 |
| `date` | 原生 date picker / 滚轮 |
| `number` | Input type=number |

## 不需要在 H5 实现的功能

以下功能仅桌面端，H5 不做：

| 功能 | 原因 |
|---|---|
| 审批模板管理 | 管理员操作，桌面端已有 |
| 全部审批（管理视角） | 管理员操作 |
| 考勤统计（管理视角） | 数据量大，适合宽屏展示 |
| 班次管理 | 管理员配置，低频 |
| 会议室管理 | 管理员操作 |
| 用户管理（OA角色） | 管理后台 |
| 职员档案管理 | 管理后台，H5 入职 H5 另行设计 |

## H5 路由结构

```
/                     → 首页（TabBar）
/approval             → 审批（TabBar，默认发起申请）
/approval/detail/:id  → 审批详情
/attendance           → 考勤（TabBar）
/attendance/detail    → 月度考勤详情
/notice               → 公告列表（从首页铃铛进入）
/notice/:id           → 公告详情
/contact              → 通讯录
/meeting              → 会议室（我的预订）
/meeting/new          → 新建预订
/profile              → 个人中心（TabBar）
/login                → 登录（SSO 重定向触发）
/callback             → OIDC 回调
```
