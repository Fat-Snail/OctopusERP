# 离散制造通用排程验收清单

## A. 主数据

- [ ] 可维护产品及版本，产品编码/版本不可重复。
- [ ] 可维护 BOM、工艺路线、工序顺序和标准节拍。
- [ ] 可维护工作中心、设备、班组、外协资源及能力编码。
- [ ] 可维护班次、休息时间、节假日、维护和不可用日历。

## B. 生产订单

- [ ] 可创建生产订单并校验计划数量大于 0。
- [ ] 订单可按工艺路线展开为有序工序任务。
- [ ] 工序任务保留订单、产品、路线和前置任务追溯关系。
- [ ] 状态只允许按规定路径流转：草稿→计划→下达→进行中→完成/取消。

## C. 排程结果

- [ ] 默认按交期优先，同等条件下资源选择结果稳定可重复。
- [ ] 只把工序分配给满足能力要求且处于可用状态的资源。
- [ ] 排程跳过休息、维护、节假日和冻结时段。
- [ ] 前置工序完成后才允许安排后续工序。
- [ ] 产能不足或无匹配资源时，任务进入“未排程”，并显示明确原因。
- [ ] 能看到资源甘特图、工序条、订单号、时间和状态。

## D. 计划生命周期

- [ ] 模拟排程不会修改已发布计划。
- [ ] 发布后形成不可变计划版本。
- [ ] 冻结区间内的任务不能被自动重排。
- [ ] 修改已发布计划时生成新版本并保留原版本。

## E. 兼容与质量

- [ ] 原服装排程页面和接口继续可读写。
- [ ] 通用排程与服装排程资源映射可追溯。
- [ ] 排程操作记录用户、时间、策略和权重。
- [ ] 后端全量自动化测试通过。
- [ ] 前端生产构建通过，浏览器可打开 `/scheduling` 并完成上述操作。

## F. PLM 制造数据同步

- [ ] PLM 商品必须先建立包含 BOM 和工艺路线的制造版本。
- [ ] 只有 `released` 制造版本出现在 MES 产品选择器。
- [ ] PLM 发布后自动通知 MES，重复事件不会创建重复快照。
- [ ] MES 同步台账显示 PLM 产品 ID、制造版本 ID、MES 产品/BOM/路线 ID、哈希和同步时间。
- [ ] MES 创建订单时引用同步记录，不允许手工输入产品或工艺路线 ID。
- [ ] PLM 不可用时禁止新建订单，不回退本地演示产品。
- [ ] 已同步的产品、BOM、路线和工序能追溯到同一 PLM 制造版本。

## 当前可验收范围

当前版本已具备 PLM 制造版本发布、MES 幂等接收、制造快照、同步台账、订单工序展开、资源约束、排程计划持久化以及通用排程看板。验收时必须使用真实 PLM 发布版本，不使用演示产品。
