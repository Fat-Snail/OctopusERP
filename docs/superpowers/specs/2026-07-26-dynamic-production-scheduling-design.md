# 通用生产排程动态化设计

## 目标

移除通用生产排程页面中固定的 `2026-07-17` 日期、示例任务和仅在浏览器内变化的计划状态。生产订单从 PLM 已发布制造版本创建并展开工序后，MES 应能基于真实工序、资源能力和资源日历完成模拟排程、计划发布、计划冻结与按日期查看，形成可持久化的排程闭环。

## 已确认规则

- 默认查看日期为用户本地当天，时区按浏览器所在时区展示。
- 默认采用“从今天当前时间开始正排”。如果用户选择未来日期，则从该日班次开始时间正排。
- 用户可切换查看日期；切换后只显示与该日期相交的真实排程时段。
- 排程数据只来自 MES 中由 PLM 已发布制造版本同步生成的生产订单、工艺路线和工序任务，不使用前端演示任务作为回退。
- 当前版本一次对一个生产订单进行模拟和发布，避免批量订单优先级规则尚未定义时产生不可解释的结果。

## 用户流程

1. 用户搜索并选择具有 PLM 已发布制造版本的商品。
2. MES 同步该制造版本，并创建生产订单、展开真实工序。
3. 新订单成为当前待排订单；页面显示订单号、商品、数量、交期和工序数。
4. 用户选择排程日期并点击“模拟排程”。
5. MES 根据工序顺序、标准工时、计划数量、资源能力和可用日历生成候选时段，同时返回未排程原因和冲突。
6. 页面以模拟结果刷新甘特图，但尚不写入正式执行计划。
7. 用户点击“发布计划”，MES 持久化计划及排程时段；发布成功后页面显示真实计划编号和发布时间。
8. 用户可冻结已发布计划。冻结截止时间写入 MES，冻结状态从后端重新读取。
9. 刷新页面或切换日期后，页面从 MES 加载真实计划，不恢复示例任务。

## 前端设计

`SchedulingBoardView.vue` 保留现有布局，但状态来源改为 API：

- 增加排程日期控件，默认值由本地当天计算，不写死具体日期。
- 创建订单成功后保存 `productionOrderId` 和订单摘要，并将该订单设为当前排程对象。
- “模拟排程”调用后端模拟接口，使用选中日期、当前时间和可配置的排程窗口生成 `from/to`。
- “发布计划”创建持久化计划；成功后保存 `schedulePlanId`，随后重新读取计划详情。
- “冻结计划”只对后端返回的 `published` 状态开放。
- 甘特图资源行、任务块、已排程数量、未排程数量、冲突信息和状态提示均从 API 响应派生。
- API 返回业务错误时展示后端中文消息；网络错误展示明确的服务不可用提示，不再只显示 Axios 通用错误。
- 当没有当前订单或没有真实排程结果时展示空状态，不展示演示任务。

## 后端设计

在现有 `/api/scheduling` 能力上补齐查询和状态闭环：

- 模拟接口返回任务、资源和时间的展示字段，避免前端拼接或依赖写死资源。
- 创建计划接口持久化模拟结果，并返回计划 ID、计划编号、状态、排程时段、未排程任务和冲突。
- 增加按日期查询计划的接口，返回与指定日期相交的计划时段及订单、任务、资源信息。
- 计划详情接口返回完整时段，而不是只有数据库实体的最小字段。
- 发布和冻结保持状态机校验；重复操作返回明确业务错误。
- 时间统一存储为 UTC，API 输入输出使用带时区的 ISO 8601；页面转换为本地时间显示。

## 排程窗口

- 选中日期为今天：`from` 为当前本地时间向后取整到分钟，并转换为 UTC。
- 选中日期晚于今天：`from` 为当日可用班次的最早开始时间；如果没有班次，由后端返回“当日没有可用班次”。
- `to` 初始为选中日期后 7 天，以允许跨日工序寻找产能。
- 甘特图单日视图只裁剪显示与选中日期相交的部分，实际计划时段不被修改。

## 错误处理

- 未选择生产订单：前端禁止模拟并提示先创建或选择订单。
- 订单没有工序：后端返回业务错误，提示检查 PLM 制造版本和工艺路线。
- 没有匹配资源能力：作为未排程任务返回，不产生 500。
- 时间窗口产能不足：作为未排程任务返回，并保留可发布时段供用户判断。
- 所有工序均未排程：禁止发布空计划。
- 数据库或未知异常由全局异常处理中间件记录，前端展示可理解的失败信息。

## 测试与验收

- 单元测试覆盖今天/未来日期的排程起点、工序顺序、资源能力匹配和无产能分支。
- API 测试覆盖创建计划、按日期查询、发布、冻结及非法状态流转。
- 前端构建和类型检查必须通过。
- 使用真实 PLM 已发布制造版本完成一次：创建订单 → 展开工序 → 模拟排程 → 甘特图变化 → 发布 → 刷新后仍存在 → 冻结。
- 验收时系统日期变化后，页面标题和请求窗口随当天变化，不再出现固定 `07 月 17 日`，除非用户主动选择该日期或历史计划确实位于该日。

## 非本期范围

- 多订单同时优化、交期倒排、换线成本、物料齐套约束、人工拖拽调整和自动重排策略。
- 这些能力将在单订单真实闭环稳定后独立设计，避免本次改造引入不可验证的调度策略。
