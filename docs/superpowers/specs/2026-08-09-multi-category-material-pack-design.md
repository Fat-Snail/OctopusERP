# PLM 多类目标准物料包设计

## 目标

在系统上线前，为现有活动叶子类目自动建立可审核的标准物料主数据和 BOM 模板草稿，使物料库不再只有手机物料，同时保证未经确认的数据不能发布到 MES。

## 适用范围

初始化以下活动叶子类目：智能手机、笔记本电脑、T恤、连衣裙、男装西服、男装衬衣、休闲零食、食品添加剂、女士香水。

智能手机已有 5 条正式物料、已发布模板和制造版本，初始化不得覆盖、降级或重复创建这些数据。其他类目生成待审核物料和模板草稿。

## 核心规则

1. 初始化随 PLM 启动自动执行，并且可安全重复执行。
2. 物料以规范化物料编码唯一；类目模板以类目和版本唯一。
3. 新增状态 `pending_review`，中文显示为“待审核”。待审核物料可以维护和绑定模板草稿，但不能用于模板发布或制造版本发布。
4. 审核通过把物料状态改为 `active`；停用使用既有 `inactive`。
5. 物料与类目为多对多关系。通用包装、标签和缝纫线可以绑定多个类目，但只保留一条物料主数据。
6. 每个活动叶子类目只有一个最新模板。初始化只填充尚未配置的 V1.0 草稿，不修改 current、historical、已有明细草稿或任何已发布制造版本。
7. 初始化数据是“标准建议主数据”，不包含供应商、采购价格、库存或未经确认的技术参数。
8. MES 仍只接收已发布制造版本，不读取待审核物料或模板草稿。

## 数据模型

### Material 状态扩展

`Material.Status` 支持：

- `pending_review`：待审核，不可发布。
- `active`：已启用，可用于模板和制造版本发布。
- `inactive`：已停用，不可新选用。

### MaterialCategoryBinding

新增物料类目绑定表：

- `BindingId`
- `MaterialId`
- `CategoryId`
- `IsPrimary`
- `Source`，初始化数据为 `standard_pack`
- `CreatedAt`

`(MaterialId, CategoryId)` 唯一。删除类目前先处理绑定；删除被绑定物料继续沿用引用保护规则。

## 初始化流程

1. 读取活动叶子类目并按类目名称匹配标准物料包定义。
2. 对每个物料编码执行 upsert：不存在则创建 `pending_review`；存在则保留人工维护的名称、规格、单位、类型和状态。
3. 幂等创建物料与类目绑定。
4. 查找该类目的 V1.0 草稿。仅当草稿存在且明细为空时，按标准顺序写入模板项。
5. 如果类目已有 current 模板、已有明细草稿或没有匹配的标准包，记录跳过原因，不做修改。
6. 返回并记录初始化摘要：类目数、新建物料数、复用物料数、新建绑定数、填充模板数、跳过数。

初始化失败以类目为边界记录错误；单个类目失败不得覆盖其他已完成类目，也不得让 PLM 无法启动。

## API 与界面

### 物料查询

`GET /api/materials` 增加 `categoryId` 过滤条件，继续采用服务端分页，页大小最多 100。

结果增加绑定类目摘要，至少包含类目 ID 和名称。物料库增加：

- 类目筛选
- 状态筛选：待审核、启用、停用
- 类型筛选
- 类目列
- 批量选择与“审核启用”

### 审核

新增批量审核接口，只允许 `admin` 或 `editor`：

`POST /api/materials/review`

请求包含物料 ID 列表和目标状态 `active` 或 `inactive`。接口验证物料存在、去重并追加审计记录，返回成功数和失败明细。

### 初始化摘要

自动启动初始化使用同一个领域服务。另提供管理员可调用的幂等重跑接口和最近一次摘要，便于验收与故障排查，但不要求用户首次手动操作。

## 发布保护

- 模板发布时，所有模板物料必须为 `active`；否则返回具体物料编码和“待审核/已停用”原因。
- 制造 BOM 保存可以引用待审核物料形成草稿，但发布制造版本时必须全部为 `active`。
- 错误在界面使用红色文本列出具体物料，不只显示“资料不完整”。
- 已发布模板、制造版本、MES 快照和排程计划保持不可变。

## 测试与验收

自动化测试覆盖：

- 初始化首次创建和重复执行零新增。
- 手机数据和已发布模板不被修改。
- 只初始化活动叶子类目。
- 共享物料只创建一次并绑定多个类目。
- 已有人工作业数据不被初始化覆盖。
- 只有空 V1.0 草稿被填充。
- 待审核物料阻止模板和制造版本发布，并返回具体物料编码。
- 批量审核权限、审计和部分失败响应。
- 十万级查询仍为服务端分页。

浏览器验收覆盖：按类目查看物料、搜索编码/名称、批量审核一个类目、发布该类目模板、为真实 PLM 商品套用模板，并确认 MES 只出现发布后的制造版本。

## 不在本期范围

- 自动生成供应商、采购价、库存和仓库批次。
- 根据商品名称猜测专用规格或用量。
- 自动发布模板或制造版本。
- 覆盖已有手机生产数据或历史 MES 快照。
