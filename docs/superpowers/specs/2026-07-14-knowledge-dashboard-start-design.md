# 知识库面板快速启动脚本设计

## 目标

在 ERP 项目根目录提供一个可重复执行的 shell 脚本，用于启动本地 Understand-Anything 知识库面板。每次启动前释放默认的 `5173` 端口，避免旧的 Vite 进程导致访问到过期 token 或启动失败。

## 行为

脚本固定将项目根目录作为 `GRAPH_DIR`，进入已安装的 dashboard 包目录，并执行 `npx vite --host 127.0.0.1`。启动前通过 `lsof` 查找监听 `5173` 端口的进程并发送终止信号；没有占用时继续启动。Vite 在终端输出带 token 的完整访问地址，用户按 `Ctrl+C` 停止当前服务。

## 错误处理

脚本使用 `set -euo pipefail`。如果 dashboard 目录不存在、`lsof` 不可用或 Vite 启动失败，脚本直接返回非零状态并保留错误输出；没有进程占用端口时不报错。

## 验证

验证脚本具备可执行权限；验证无进程占用时可以启动；验证重复执行时先终止旧端口进程，再由新 Vite 进程监听同一端口。验证完成后不修改业务代码。
